## How to cite this repository

If you use these tutorials, notebooks, or code in a thesis, paper, or teaching material, please cite the repository using the **Cite this repository** menu on GitHub (enabled by the root `CITATION.cff` file). Cite LSEG/Refinitiv separately as the underlying data provider. When available, prefer the DOI of the particular archived release; no DOI has been assigned in this package.

**CodeBook tutorials:** [Browse CodeBook notebooks](CodeBook/README.md).
